# Scrolls of Light — translation glossary (Spanish `es`, Greek `el`)

Game for children 8–15. Address the player as **tú** (es) / **εσύ** (el), warm, simple, lively.
Spanish: neutral international Spanish (understood in Spain and Latin America); use "ustedes", never "vosotros"; avoid regional slang.
Greek: modern demotic Greek, monotonic accents, natural for Greek children. Plural address: "εσείς".

## Bible text policy (important)
Modern Bible translations (RVR1960, NVI, NTV, DHH, the Greek Bible Society's ΤΕV/"Η Αγία Γραφή στη Νεοελληνική") are copyrighted.
Do NOT copy them. Write short, faithful, kid-friendly retellings in your own words, the same way the German version does.
- Spanish verse citation shows "según Juan 3:16" (that prefix comes from the `v.ref` string; reference itself is "Juan 3:16").
- Greek verse citation shows "Ιωάννης 3:16 (απόδοση)" (`v.ref` = "{0}", `v.src` = "(απόδοση)").
- Reference format: `Book chapter:verse` with a colon, e.g. "Génesis 1:1", "Γένεση 1:1"; ranges "Juan 3:16-17"; several "Génesis 5:27; 9:29".

## Math notation
- es: multiplication "×", division "÷", decimal point "." (e.g. 2.5), thousands "15,000" → write "15 000"? No: write 15.000? Use **15 000** (thin space) to avoid ambiguity. Percent "25 %".
- el: multiplication "·", division ":", decimal comma "2,5", thousands "15.000", percent "25%".
